# RCaaS: Reflective Auditor Prototype

## Mission
To demonstrate **Agentic Reflection** in compliance automation. This system moves beyond binary "Pass/Fail" logic to ingest contextual policy data and perform self-correcting audits.

## Key Features
* **Reflective Logic:** Self-corrects audit results based on unstructured context (e.g., environmental buffers).
* **Data Persistence:** Automated logging of every decision to `audit_history.csv` for 100% traceability.
* **Full-Spectrum Execution:** Built with FastAPI for high-scale, asynchronous performance.

## Technical Stack
* **Language:** Python 3.x
* **Framework:** FastAPI (Uvicorn)
* **Data Format:** JSON & CSV
